# AWS Solutions Architect Associate — Lecture Sources

This directory contains local lecture videos and extracted transcripts from Adrian Cantrill's **AWS Certified Solutions Architect – Associate (SAA-C03)** course, kept for personal study and wiki synthesis.

## Course Reference

[Learn Cantrill — VPC Flow Logs](https://learn.cantrill.io/courses/1820301/lectures/41301379) is a lesson within the course, rather than a link to the entire course collection.

## Organization

Materials are grouped by topic, with one Markdown transcript per video:

```text
<topic>/
  videos/       Original lecture recordings
  transcripts/  Extracted transcripts in markdown format
```

For example, the local `CloudFront/` folder contains the CloudFront-related recordings and transcripts. Synthesized explanations live separately in the [wiki](../../../wiki/index.md).

## Private Storage

The videos and transcripts contain proprietary course material. Topic-level `videos/` and `transcripts/` directories are excluded from Git by the repository's `.gitignore` and are not pushed to GitHub. **This README is tracked and can be pushed to GitHub.** Keep local video paths and transcript links out of wiki pages so the wiki remains self-contained.
